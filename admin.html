Backup & transfer

Listings live in this browser. Export regularly.

How storage works. Because this is a static HTML site with no server, listings and photos are saved in this browser's local storage — they are visible on this device only, and a different computer or a cleared browser will show the sample set again. Export to listings.json to back them up or to move them to another machine. Photos are automatically downscaled to 1600px on upload; the quota is about 5MB, so keep an eye on the Storage Used figure above.
